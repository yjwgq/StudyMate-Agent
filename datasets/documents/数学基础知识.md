# 数学基础知识笔记

## 第一章：代数基础

### 1.1 一元一次方程

一元一次方程是只含有一个未知数，且未知数的最高次数为1的方程。
标准形式为：ax + b = 0（其中 a ≠ 0）。

求解步骤：
1. 移项：将含未知数的项移到等号一边，常数项移到另一边
2. 合并同类项
3. 系数化为1

示例：求解方程 3x - 5 = 10
- 移项：3x = 10 + 5
- 合并：3x = 15
- 系数化1：x = 5

### 1.2 一元二次方程

一元二次方程的标准形式为：ax² + bx + c = 0（其中 a ≠ 0）。

求根公式：x = (-b ± √(b² - 4ac)) / (2a)

判别式 Δ = b² - 4ac：
- 当 Δ > 0 时，方程有两个不相等的实数根
- 当 Δ = 0 时，方程有两个相等的实数根
- 当 Δ < 0 时，方程没有实数根

示例：求解方程 x² - 5x + 6 = 0
- Δ = 25 - 24 = 1 > 0
- x = (5 ± 1) / 2
- x₁ = 3, x₂ = 2

## 第二章：微积分基础

### 2.1 导数的定义

函数 f(x) 在点 x₀ 处的导数定义为：
f'(x₀) = lim[Δx→0] (f(x₀ + Δx) - f(x₀)) / Δx

导数的几何意义是函数曲线在某点的切线斜率。

### 2.2 基本求导公式

- 常数函数：(C)' = 0
- 幂函数：(xⁿ)' = n·xⁿ⁻¹
- 指数函数：(eˣ)' = eˣ
- 对数函数：(ln x)' = 1/x
- 正弦函数：(sin x)' = cos x
- 余弦函数：(cos x)' = -sin x

### 2.3 积分基础

不定积分是导数的逆运算。
基本积分公式：
- ∫ xⁿ dx = xⁿ⁺¹ / (n+1) + C （n ≠ -1）
- ∫ eˣ dx = eˣ + C
- ∫ (1/x) dx = ln|x| + C
- ∫ cos x dx = sin x + C
- ∫ sin x dx = -cos x + C

牛顿-莱布尼茨公式：
∫[a,b] f(x) dx = F(b) - F(a)
其中 F(x) 是 f(x) 的一个原函数。

## 第三章：几何基础

### 3.1 平面图形公式

- 长方形面积 = 长 × 宽
- 正方形面积 = 边长²
- 三角形面积 = 底 × 高 ÷ 2
- 圆的面积 = π × 半径²
- 圆的周长 = 2 × π × 半径

### 3.2 立体图形公式

- 长方体体积 = 长 × 宽 × 高
- 正方体体积 = 边长³
- 圆柱体体积 = π × 半径² × 高
- 球体体积 = (4/3) × π × 半径³
- 球体表面积 = 4 × π × 半径²
